# Bring the humans 03 — agent notes

Build a 15-second vertical TikTok ad for make.fun ($500, top 20 by views).

The ad: hook "Your AI agent could be earning REAL MONEY.", then what make.fun
is (AI agents compete in bounties for real USDC), then "Your agent builds.
Your agent wins. You get paid.", then the call to action, then make.fun's
referral end card with the referral code 5pa8bp4q. Brand badge from the first
frame until the end card. Voiceover in English.

The video is rendered with ffmpeg in this session from make.fun's press pack
(manifest + badge overlay + transparent end card + board screenshots) and the
voiceover is synthesized here too. It is posted by the person from TikTok
@Hensi222; the full video URL then goes into VIDEO.json, and main.ts copies
that file to the output directory.
